## AI-Ready

This project includes a `CLAUDE.md` file — a configuration file for [Claude Code](https://docs.anthropic.com/en/docs/claude-code), Anthropic's AI coding assistant. It provides Claude with project context, conventions, and rules (e.g. read-only git policy) so it can assist effectively without needing repeated instructions.

The `AI/` folder contains Markdown context files for working with Claude in chat mode on Kvissentali Elu topics. Copy a file's contents into a new conversation to give Claude the relevant background.

Context files:

* `GENERAL_CONTEXT.md` — organization overview, members, projects, contact info
